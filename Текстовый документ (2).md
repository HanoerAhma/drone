### 3.3. Подключение платы LM317
Одним из практических заданий радиомонтажного этапа была сборка регулируемого стабилизатора напряжения на микросхеме LM317.
**LM317** — трёхвыводная интегральная микросхема линейного регулируемого стабилизатора напряжения положительной полярности. Выходное напряжение задаётся в диапазоне примерно от 1,25 В до 37 В с помощью двух внешних резисторов по формуле:
$$V_{out} = 1{,}25 \cdot \left(1 + \frac{R_2}{R_1}\right)$$
![Фотография собранной платы со стабилизатором напряжения на LM317](foto_raboty_1.jpg)  
**Рис. 4.** Фотография собранной платы со стабилизатором напряжения на LM317
| Компонент | Обозначение | Функция в схеме |
|---|---|---|
| Микросхема LM317 | U1 | Регулируемый линейный стабилизатор напряжения |
| Резистор задающий | R1 (240 Ом) | Задаёт опорный ток через вывод ADJ |
| Подстроечный резистор | R2 (потенциометр) | Регулирует выходное напряжение |
| Входной конденсатор | Cin, 0,1 мкФ | Подавляет ВЧ-пульсации на входе |
| Выходной конденсатор | Cout, 1 мкФ | Сглаживает выходное напряжение |
| Клеммы Vin / Vout / GND | — | Подключение источника, нагрузки и общего провода |
![Фотография схемы LM317](p_16_skhema.jpg)  
**Рис. 5.** Фотография схемы LM317
Входное напряжение подаётся на вывод IN; между IN и GND установлен Cin. Вывод OUT — выход стабилизированного напряжения; между OUT и GND — Cout. Между ADJ и GND — R1, между OUT и ADJ — потенциометр R2. Изменяя R2, я регулировал выходное напряжение, контролируя результат мультиметром.

### 3.5. Задание 3. Численное моделирование: груз на пружине (вариант 3)
Цель: исследовать устойчивость численных методов интегрирования на примере гармонического осциллятора.

#### 3.5.1. Постановка задачи
Уравнение движения: $a = -\frac{k}{m} x$. Параметры варианта 3: $m = 1$, $k = 4$. Начальные условия: $x_0 = 1$, $v_0 = 0$.

#### 3.5.2. Реализация на Python
Программа woRK3_spring.py реализует явный и полунеявный (симплектический) методы Эйлера. Построены:

фазовые траектории ($x$–$v$) при $\Delta t = 0{,}05$ с;
графики относительной энергии $E/E_0$;
шесть кривых энергии при $\Delta t = 0{,}1;\ 0{,}05;\ 0{,}02$;
демонстрация устойчивости: при $|\omega \Delta t| < 2$ энергия ограничена; при $\Delta t = 1{,}1$ ($\omega \Delta t = 2{,}2$) — неустойчивость.
Выводы:

явный Эйлер систематически увеличивает энергию;
полунеявный Эйлер сохраняет энергию при $|\omega \Delta t| < 2$;
уменьшение $\Delta t$ замедляет рост ошибки у явного метода.
python3 woRK3_spring.py
### 3.6. Задание 4. Drone Code Arena: гонка по чекпоинтам
Цель: разработать алгоритм автопилота для прохождения маршрута с чекпоинтами на карте с препятствиями.

#### 3.6.1. Постановка задачи
Дрон стартует в S, проходит чекпоинты 1 → 2 → 3, затем добирается до G. Препятствия (#) непроходимы. Функция build_route(grid) возвращает команды: UP, DOWN, LEFT, RIGHT.

#### 3.6.2. Алгоритм решения
Реализован поиск кратчайшего пути методом BFS (поиск в ширину):

S→1→2→3→G

Фрагмент решения (04.1--Race/Gudantov/solution.py):

def build_route(grid):
    checkpoints = ["1", "2", "3", "G"]
    current_pos = find_symbol(grid, "S")
    full_route = []
    for symbol in checkpoints:
        target_pos = find_symbol(grid, symbol)
        part_route = bfs_between_points(grid, current_pos, target_pos)
        if not part_route and current_pos != target_pos:
            return []
        full_route.extend(part_route)
        current_pos = target_pos
    return full_route
